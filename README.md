# Hemanath M — Personal Portfolio

A responsive, professional white-theme portfolio built with plain HTML, CSS and JavaScript. No build tools or framework are required.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For local development, you can also open the folder in VS Code and use the Live Server extension.

## Before publishing — personalize these details
- In `index.html`, replace `YOUR_EMAIL@example.com` with your real professional email.
- Update the GitHub and LinkedIn links to your profile URLs.
- Add project repository/demo links where available.
- Add exact dates, job title and responsibilities for your University of Madras contract role.
- Verify education, certification names and project descriptions.
- Add a resume PDF in `assets/` and create a Download CV link if you want one.

## Publish free with GitHub Pages
1. Create a GitHub repository, for example `hemanath-portfolio`.
2. Upload the contents of this folder (keep `index.html` at the repository root).
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will provide your public website URL.
